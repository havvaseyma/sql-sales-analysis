# Online Advertising Campaign Analysis (SQL)

This project analyzes Google and Facebook online advertising data using SQL in DBeaver. I worked with the facebook_ads_basic_daily and google_ads_basic_daily tables, supported by facebook_adset and facebook_campaign, from the ads_analysis_goit_course database. The queries calculate average, maximum and minimum daily spend for each platform, and find the top 5 days by total ROMI across Google and Facebook. They also identify the campaign with the highest weekly value, the campaign with the largest monthly reach growth, and the ad set with the longest continuous run. Each question has its own .sql file.

**Tools:** SQL, DBeaver
